# FIH — Platform Setoran Gmail Mobile-First

Paket aplikasi web modular (`index.html`, `style.css`, `app.js`, `supabase-config.js`, `vercel.json`) siap unggah ke GitHub/Vercel.

## Fitur Utama
1. **Navigasi Bawah Floating Pill Bar**: Efek kaca transparan (*glassmorphism*), kapsul aktif, lencana merah notifikasi, dan animasi transisi *smooth* ala iPhone.
2. **Dashboard Lengkap**: Grafik pendapatan dinamis 7 hari, informasi khusus dari Admin Panel, link komunitas Telegram & WhatsApp Channel, 5 poin Rules Setoran Gmail, Syarat & Ketentuan, serta Penjelasan Umum Fitur Website.
3. **Setoran Gmail (Good & Captha)**: Pemisahan jalur setoran, info estimasi pengecekan **24–30 jam**, validasi kata sandi huruf kecil semua, serta **Generator Nama Gmail** instan tanpa AI.
4. **Leaderboard**: Peringkat top penyetor dengan syarat **minimal 100 setoran Gmail** dan hadiah **Juara 1: Rp15.000**, **Juara 2: Rp10.000**, **Juara 3: Rp5.000**.
5. **Profil, Notifikasi & Laporan**: Edit username, ganti foto profil, pusat notifikasi real-time, serta form laporan/umpan balik.
6. **Admin Panel**: Kontrol **Buka / Tutup** jalur setoran Good & Captha, **verifikasi semi-otomatis 1-klik** (Salin Email, Salin Sandi, Good/Captha/Tolak), kelola Informasi Dashboard, pantau laporan user, dan log aktivitas login.
7. **Autentikasi Bersih**: Menggunakan Supabase Auth standar tanpa SQL langsung di alur login.
